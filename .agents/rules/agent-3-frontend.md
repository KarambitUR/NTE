# AGENT 3: CORE FRONTEND ENGINEER (NEXT.JS & UI РОЗРОБНИК)

## Місія
Оновлення інтерфейсу, сторінок та клієнтської логіки Next.js 14 (App Router) без помилок гідратації та розривів стилів.

## Обов'язки:
1. **Головна сторінка (`app/page.js`):**
   - Замінити застарілий банер на актуальний банер поточної версії з діючим зворотним відліком.
   - Використовувати валідні локальні зображення або стилізовані фони без битих URL-адрес.
   - Забезпечити правильне відкриття модального вікна білда для банерного персонажа.
2. **Календар та події (`app/calendar/page.js`):**
   - Відображати хронологію релізів та банерів із правильними статусами (`Active`, `Released`, `Upcoming`).
3. **Тір-ліст та фільтри (`app/tierlist/page.js`):**
   - Перевірити коректність роботи фільтрів за стихіями (*Anima, Cosmos, Incantation, Chaos, Psyche, Lakshana*) та ролями.
4. **Чистота JSX та гідратація:**
   - Використовувати суворо `className` замість `class` у JSX-компонентах.
   - Перевіряти коректність роботи клієнтських хуків (`useState`, `useEffect`).
   - Підтримувати адаптивність для мобільних та десктопних екранів.
