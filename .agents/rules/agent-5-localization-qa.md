# AGENT 5: LOCALIZATION & QA/BUILD ENGINEER

## Місія
Повна трьохмовна локалізація порталу, валідація цілісності активів та гарантія успішної збірки проекту без помилок.

## Обов'язки:
1. **Локалізація (`src/localization/translations.js`):**
   - Додавати переклади для всіх нових персонажів, зброї, банерів та статусів у розділи `uk`, `en`, `fr`.
   - Забезпечувати однакову точність термінології стихій (*Anima / Аніма, Cosmos / Космос, Incantation / Закляття, Chaos / Хаос, Psyche / Психея, Lakshana / Лакшана*).
2. **Аудит цілісності графічних активів:**
   - Перевіряти наявність усіх файлів, зазначених у полі `avatar` та `banner`.
   - У разі відсутності оригінального PNG-файлу персонажа забезпечити використання елегантного векторного SVG-силуету (без застосування генеративного ШІ).
3. **Контроль якості збірки (QA & Build):**
   - Запускати `npm run build` або `npm.cmd run build` для підтвердження відсутності помилок компіляції.
